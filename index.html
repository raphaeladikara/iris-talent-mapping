Hubungkan website ini dengan Google Sheets kamu.
1
Buat Google Spreadsheet baru
Buka sheets.google.com dan buat spreadsheet baru dengan nama "IRIS Talent Mapping".
2
Buka Apps Script
Di spreadsheet, klik Extensions → Apps Script. Hapus semua kode yang ada, lalu paste isi file Code.gs yang sudah disediakan.
3
Deploy sebagai Web App
Klik Deploy → New Deployment. Pilih type Web App. Set Execute as: Me dan Who has access: Anyone. Klik Deploy, copy URL-nya.
4
